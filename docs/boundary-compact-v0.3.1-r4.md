# v0.3.1 r4：收集反向條件與縮小目錄

日期：2026-10-06。版本仍為 0.3.1，修訂識別為 `2026-10-06-r4`。程式與驗收腳本固定在 `8f2daab1536ad9e30abc74479a8dfa3854766d57`；介面功能先於 `eb347bd150cc36de6035eea55df5877723e8bd61` 提交。兩筆已同步 GitHub 私人庫。

## 使用者回報與原因

使用者確認 r3 初步能跳轉，但收集往較早處前進一兩次便反向，縮小目錄隨筆數變長，並要求橫排「目錄」及簡約非綠色配色。

程式檢查確認 r3 把兩次約 1.6 秒的相同掛載窗口當成切換方向條件，未檢查真正捲動頂端。這能解釋慢掛載或暫時停滯時過早反向；本輪以獨立本機渲染器驗證修正，沒有把本機結果視為使用者 ChatGPT 站點的根因實證。

## 收集規則

- 持續選取目前相鄰掛載窗口最遠的外層訊息殼，以 Firefox 原生 `scrollIntoView` 向較早處前進，保留每次觀察到的穩定提問。非相鄰的固定尾端不作為跨越未知中段的捷徑。
- 一次收集等待最多約 6.5 秒，容納 5 秒的延遲掛載。中段沒有新窗口時保持方向；連續三次無進展會有限停止，不宣稱收齊。
- 只有實際捲動容器到頂、較早端外層殼仍可見、沒有載入指示，且同一根節點、訊息殼、窗口、捲動尺寸和實際邊界座標連續穩定至少 6 秒，才可切換往較新處掃描。還需兩次同方向探測被邊界限制，確認無法再前進。
- 載入提示、容器／殼替換、尺寸、捲動位置或邊界座標改變，都重新計時。底端也使用相同證據，結束巡覽不等於已核對完整歷史。
- 保留最多 5 分鐘、2400 步、單批 8 秒及快取容量限制。取消、頁面切換與 epoch 變更保留原有檢查；不恢復 session／歷史 API。

## 介面規則

縮小時 0–5 筆依實際數量顯示；超過 5 筆只顯示 5 個分散於已收錄範圍的標記，包含首尾。這是顯示限制，完整快取、搜尋與列表都保留。展開時顯示全部標記和全部提問，標記區可捲動。

「目錄」使用橫排且不換行。亮色為白／灰、深色為炭灰，強調與定位框為淡靛色；不再使用綠色。120 筆資料的縮小目錄高度為 137px，不再隨筆數增長。

## 驗收與交付邊界

主驗收與 GPT-6.1 Sol high 獨立固定 SHA 驗收結果、建置指紋見 [證據目錄](evidence/boundary-compact-2026-10-06/README.md) 與 [獨立驗收](acceptance-v0.3.1-r4.md)。所有新增渲染器和截圖都是 Firefox 157 的 localhost 合成資料，不含帳號、聊天內容或登入 profile。本輪未完成真實 ChatGPT Firefox addon LIVE，不能宣稱所有線上掛載情境均已修好。

收集回歸的 40 筆效能測試上限由 55 秒調為 90 秒，以納入兩端穩定探測；精確 40 筆 ID／順序、跨過 60000px 回答及取消檢查仍保留。跳轉本身的 60 秒／60 步限制未增加。大型頁首或 padding 若阻礙原生邊界探測，可能有限停止，已收錄資料仍可用。

交付位置為 sibling `outputs/Firefox-測試版-v0.3.1-r4/manifest.json`；移除舊暫時附加元件、載入 r4 的 manifest 並重新整理 ChatGPT。診斷應顯示 `2026-10-06-r4`。r3 及更早交付資料夾保留作為歷史版本。
