# v0.4.0：已觀察區段快速導航

2026-10-14。以 v0.3.5 程式與既有本機診斷工具為基準；工作分支 feat/warm-navigation-v040。MINOR 更新的原因是啟用新的導航模式。

## 行為

首次看見的區段：沿目前掛載邊緣逐步載入、保存提問與順序。已在本次頁面觀察過的目標：使用相鄰提問的實測距離鏈與目前掛載錨點計算目標位置，瞬間捲到附近，再核對真正掛載的穩定 ID／提問內容並對齊、標亮。只要距離鏈足夠就可用，不強迫先收集整段。

資料已 fetch 與 DOM 目前已掛載是不同狀態。本插件不讀取登入憑證或私有 history API；以本頁 DOM 見證來推導快速路徑，不宣稱可以直接得知 ChatGPT 的網路快取內容。

## 明確限制與回退

- 距離鏈每一段都必須有兩端同時掛載的測量；不以平均高度、訊息編號比例或孤立回答高度補缺口。
- 目標必須曾在本頁測量。已保存目錄可跨 F5／SPA 保留；幾何資料屬當次頁面，不存入 storage、不跨頁套用。
- 寬度差超過 8px、對話／順序版本改變、滾動容器替換時，不使用舊幾何直接跳。
- 每次导航最多一次快速嘗試，等待重掛載最多 2.2 秒，受原導航總截止時間及取消信號約束。未命中即清除失效幾何、若掛載內容或排版已變，依當前位置回退；若仍是跳前完全相同的 ID 集合、容器尺寸／高度／user 錨點座標（2px 內），先復位到跳前游標再逐段走，避免停在固定尾端旁。不能重複猜位置形成跳動。
- ID、內容或可見性未核對時不能回報成功或標亮其他訊息。巨型回答、延迟掛載、固定尾端訊息、排版改變與使用者停止都納入測試。
- 收集整段仍採向上路徑；收集時不對齊位於視口下方的邊緣造成往回捲。頂端停止保留現有六秒穩定／兩次夾住探測，避免把中途停滯當成頂端。

## 驗證與交付

新增包含首次 fetch、fetch 後仍只掛載局部 DOM 的 Firefox localhost renderer；驗證冷收集、暖區段跨大距離跳轉、重新進入已載入區段不再 fetch、幾何失效回退、停止、寬度／對話失效。記錄耗時、捲動命令、fetch 次數和精確標亮 ID，與強制逐段基準比較。另跑型別、核心／幾何／持久化／互動／設定測試，以及頂端停止與 F5／SPA 回歸。原生 Firefox localhost 與真正 ChatGPT LIVE 的證據分開；LIVE 未執行必須標 PENDING。
