# v0.4.1 快速導航未啟動排查

2026-10-15。使用者回報 v0.4.0 選取远處提問仍全程逐段移動。這是實際使用失敗，不能以 localhost 的暖快取測試通過取代。真實 Firefox ChatGPT 的根因尚待當頁診斷核對。

已確認的程式缺口：jumpObserved 使用全域 store.ordered 作門檻；seekDirection 卻能使用目標與錨點所在的已排序區段。與目標無關的未確認群組因此能阻止原本有完整實測距離鏈的快速導航。其次，所有未啟動原因都只有 result=cold，無法區分沒看過目標、尺寸變動或缺少距離鏈。

本次 PATCH 只修正上述門檻與診斷。快速位置仍需目標所在已排序區段的完整相鄰實測距離鏈，同頁／同 epoch／同容器／相容寬度；不以編號比例、平均高度或舊绝對座標猜位置。F5 保留文字目錄但幾何冷啟動，首次重新看見區段前仍可能逐段載入。載入快取不等於 DOM 有可定位節點。

新增 fast.skipReason、eligibility 與獨立保留的 fast.lastAttempt。導航末段的 mounted-edge-anchor 不再覆蓋快速嘗試的證據。目標 ID、正文、網址與登入資訊不匯出。介面在回退時顯示可讀的原因，避免使用者把逐段導航當作已成功快跳。

驗證必須包含：同區段完整距離鏈但全域 order=false 的 v0.4.0 前後比較；缺少中間距離、目標未觀察、尺寸變動的保守回退；既有暖跳、取消、SPA、F5、排版錯估回歸。合成測試與真正 ChatGPT 實測分開標示。本次候選的 LIVE 為 PENDING，不宣稱已修好使用者的實際頁面。

每功能或 30 分鐘有效工作 commit，同步私人 GitHub 的 fix/fast-eligibility-v041；禁止本機網路 Git／GCM。未完成真實核對前，不覆蓋 v0.4.0 tag 或原包，也不把候選冒充正式驗收。
