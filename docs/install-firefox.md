# Firefox v0.4.0 安裝與更新

可安裝資料夾：`outputs/Firefox-測試版-v0.4.0/manifest.json`；version 0.4.0，revision 2026-10-14-v040。與舊版相同 addon ID，程式沒有清除本機目錄資料或變更儲存格式。

1. 在 Firefox 開啟 `about:debugging#/runtime/this-firefox`，選「載入暫時附加元件」，選 v0.4.0 資料夾中的 manifest.json。若沿用現有安裝位置，將新版檔案放入該資料夾後按原附加元件「重新載入」。
2. 核對附加元件顯示 0.4.0，再重新整理 ChatGPT 分頁。目錄預設自動開啟行為依既有設定，Shift+O 展開，Esc 收合。
3. 對舊長對話先使用「收集整段對話」或自行捲過各區段。之後選取已看過的遠處提問，應直接跳到附近、核對後標亮。新內容會照原本機快取邏輯加入。
4. 若視窗寬度／版面大幅變更或目標尚未載入，會回退逐段導航，可按「停止」取消。F5／切換對話後文字目錄仍保存；本次頁面的幾何重新建立，不能把還原的文字目錄視為已取得快速位置。

收集最多10分鐘，設定可改1–10分鐘；第一次收集沿當前位置向上，不會清空目錄。穩定頂端確認後結束，保留收錄資料。只有到達可核對的頂端邊界才宣稱收集停止，不宣稱完整伺服器歷史已核對。

需要現場排錯時可額外載入 `outputs/Firefox-實測記錄器-v0.1.1/manifest.json`。記錄器與產品是不同附加元件；它只在你按開始後記錄幾何和白名單診斷，可手動下載JSON，沒有聊天文字、真實ID、網址或登入資料。

本版ZIP是開發測試包，透過上方暫時附加元件流程載入；未做Mozilla簽章或商店上架。Firefox localhost與ChatGPT LIVE的結果請看交付報告。
