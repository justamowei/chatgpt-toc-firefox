# Firefox v0.3.5 更新與使用

正式 manifest：outputs/Firefox-測試版-v0.3.5/manifest.json 或 dist/firefox/manifest.json；version 0.3.5，revision 2026-10-08-v035。

1. 保留既有索引：把新版資料夾內檔案覆蓋到目前載入插件的資料夾，保持同一 addon ID，在 Firefox about:debugging →「這個 Firefox」按「重新載入」。不要先卸載或清除索引。
2. 首次安裝：從上述頁面「載入暫時附加元件」選新版 manifest，允許 chatgpt.com 網站權限。重整已開啟 ChatGPT 分頁；之後新頁面預設自動啟用。
3. 點目錄或輸入框外 Shift+O 開啟，Esc 收合。縮小格子只有目前掛載可定位提問，展開保留已收錄提問。
4. 等 scope 顯示「已儲存於本機」，切換對話或 F5 可直接恢復已保存提問與原本排序，不需要重新收集。保存項目可點選尋找，重新掛載時核對 ID 與正文；舊分支矛盾資料只供搜尋。
5. 「重建整段目錄」會清空此對話目錄（不刪聊天），先移到最底再向上收集，到頂停止。通常舊對話首次使用一次；後續新增沿用保存索引。預設最多 10 分鐘。面板「設定」→收集時間選 1–10 分鐘→「儲存收集時間」，下一次執行生效。到達穩定頂端自動停止，也可按「停止」；Alt 不停止。

每對話 5000 筆／500 萬正文，profile 最近使用 12 個對話／600 萬 JSON 字元；無痕不保存。暫時 addon 未簽章，Firefox 重啟可能移除，不承諾卸載後快取。Firefox 157.0.1 原生合成驗收 5 項通過，ChatGPT LIVE 未完成；見 [完整報告](release-v0.3.5.md)。

編號代表已由起點核對的提問序號；未確認起點顯示「暫N」。搜尋不重編號，F5與切换對話恢復保存編號。重建若中斷，可使用已收錄資料；再次重建會重新清空目前對話目錄。
