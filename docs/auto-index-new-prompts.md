# v0.3.7 測試版：身分衝突時仍顯示新提問

v0.3.6 實際回報：Firefox 中新提問未收錄，F5 也未恢復。診斷顯示 2 個使用者泡泡，收錄 0、掛載 0、隔離 1。

以原 v0.3.6 在獨立 Firefox localhost 重現：兩則文字不同的提問共用一個回合鍵時，同樣出現 0／0／1。v0.3.7 在這個情境將共用鍵視為不可靠，兩則提問會分開顯示；只有身分有疑義的舊紀錄轉為僅供搜尋，其餘資料不受影響。身分未能唯一確認時，該列只在掛載期間顯示；一旦取得各自的識別碼，才可跳轉及保存。診斷增加辨識、衝突與暫時列數量，並列出隔離原因，不包含聊天內容或訊息 ID。

驗證：在同一個 localhost 情境確認兩列可見、補上識別碼後各留一列且可定位，第三則同頁新提問也會自動加入。這是可重現的失敗路徑，並未確認現場 ChatGPT 一定用了相同的身分鍵。真實頁面仍待核對。安裝候選使用 dist/firefox/manifest.json，原 v0.3.5 保留。

## v0.3.6 的原修正
以 v0.3.5 為基準修正。當新提問先以明確的使用者訊息泡泡掛載在對話主區域、尚無外層回合或識別碼時，目錄也會先顯示；取得穩定 ID 後更新同一列，啟用定位及本機保存。不索引輸入框草稿或回答內的引用；不新增歷史 API 或自動捲動。

獨立 Firefox 的 localhost 驗證：同一會話連續新增兩筆，未重整即可看到，ID 補齊後各只留一筆，儲存後重新整理可讀回。草稿與回答引用不進目錄。真實 ChatGPT 仍待核對。

安裝候選：專案 dist/firefox/manifest.json。原 v0.3.5 安裝檔和所有 tag 保留；本候選另存工作分支，未建交付 tag。依使用者更正，本修正接續 v0.3.5 採用 v0.3.6；舊 v0.3.6 實作維持撤回。
