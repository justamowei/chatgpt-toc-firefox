# Firefox v0.2.0 完整歷史實驗版

已實作完整提問目錄與提問全文搜尋。透過使用者主動按「載入完整目錄」唯讀取得目前對話的歷史；完整清單留在此分頁記憶體，畫面仍按需掛載訊息，因此不再因只顯示附近 6–7 題而縮小清單。回答全文不加入搜尋。

## 安裝與操作

1. 在 Firefox `about:debugging` 移除舊的「ChatGPT 對話導航器」暫時附加元件。
2. 點「載入暫時附加元件」，選新版資料夾 `Firefox-原型-v0.2.0/manifest.json`；請確認版本為 0.2.0。
3. 重整原 ChatGPT 分頁，點 Firefox 附加元件按鈕開啟目錄。
4. 在已儲存的 `/c/<對話ID>` 對話按「載入完整目錄」。新對話須先送出提問，讓網址取得對話 ID；自訂 GPT 對話 `/g/<名稱>/c/<對話ID>` 也有支援。
5. 成功時顯示「已讀取完整歷史 N 則提問 · 伺服器分支」，搜尋涵蓋所有已取得的提問。畫面核對數可能仍為 6–7，這是目前掛載數，完整目錄總數不會因此縮小。
6. 點擊提問會嘗試定位；若頁面尚未掛載，會有限地尋找。網站若需真實捲動才能掛載，請手動捲至附近再定位。畫面身分完全無法對應時保留全文搜尋，暫停定位。
7. 「停止」可中止讀取與導航。換對話、已觀測編輯／重新生成／分支變更會撤銷舊目錄；需要時再按載入。返回剛才位置只在該閱讀錨點仍有效時使用。

## 資料與限制

- 唯讀目前對話；不列舉帳號其他對話，不送第三方。聊天及登入 token 不寫入 storage、診斷、檔案或 Git；設定只存原有開關。停用此頁清除快照、任務與目錄。
- 明確讀完分頁、拒絕缺失 cursor／無進展／衝突 ID，legacy 僅新版路徑第一頁 404 後沿 current_node 到 root；完成後再次核對 head。缺資料、格式不支援、超時、超限、401／403／429 不會把部分結果當成成功。
- 本次固定上限：60 秒、每請求 8 秒、100 頁、10,000 訊息、單頁 2 MiB／累計 16 MiB、單題 262,144 字元。超限會顯示失敗，仍可使用畫面掛載目錄。
- 使用網站內部介面，可能隨 ChatGPT 改版改變。遇「歷史格式尚未支援」時請回覆提示文字；不必提供聊天內容或憑證。
- 伺服器路徑與目前掛載子集相符不等於整個 UI 分支已驗證；歷史 API、真實登入、完整預期提問集合與所有遠距跳轉仍要在真實長對話核對。沒有 revision／parent 的回應，只能依協定的分頁結束與 head 重新讀取降低混合風險。
- 此為未簽章實驗版。ZIP 可解壓後載入 manifest，正常 Firefox 不接受未簽章套件作永久安裝；重啟後須重新暫時載入。

## 驗證紀錄

合成測試使用無帳號的獨立 Firefox 157 profile；200 題只掛載 7 題，核對完整 ID／順序、離屏搜尋、十個遠距目標、停止晚到、編輯／重新生成／全替換分支、卸載後 witness、返回與失敗降級。實際結果與固定 source SHA 見 acceptance-v0.2.0.md；真實帳號與長對話驗收維持 PENDING。
