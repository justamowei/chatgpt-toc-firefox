## r3：核對定位標示與清除本頁目錄

點選提問時以核對通過的訊息泡泡本身捲動，避免共用回合外層把畫面帶到另一則。成功後清單藍色列與訊息標亮指同一提問；手動閱讀後回到依實際對話視窗判定的目前列。

「清除本頁目錄」清除目前對話的本機索引，等待本分頁舊寫入結束後才刪指定對話的紀錄，隨即從目前已掛載內容重新收錄。不清除 ChatGPT 訊息或其他對話索引；若另一分頁還開著同一對話，它之後仍可重新保存自己觀察到的資料。

獨立 Firefox localhost 驗證：共用外層回合的兩則提問能跳到確切泡泡，藍色列與標亮一致；清除後重新整理只保留掛載提問，另一個對話的本機目錄可讀回。真實 ChatGPT 仍待核對。
