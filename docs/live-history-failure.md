# 真實 Firefox 完整目錄失敗與修正版交付門檻

日期：2026-10-03（Asia/Taipei）。已交付 v0.2.0，runtime source 95c2694e03185f66a1a0dc19a62bc8280b61420e。

## 已確認事實

使用者回報完整目錄沒有改善，仍隨 ChatGPT 頁面依次掛載的筆數顯示；按「載入完整目錄」後的原文提示為「對話超出本次載入上限，未宣稱完整；仍可使用已掛載目錄。」因此完整歷史讀取返回 HistoryError limit，完整快照沒有套用。這不是成功取得全量後單純因 DOM 卸載縮小清單的證據。

產品目標標記 **LIVE FAIL**。既有 38 單元與 42 原生合成案例通過是歷史回歸證據，不足以抵銷實際失敗。先前只憑合成驗收交付修正，未滿足使用者實際使用目標。

## 待確認原因與開發範圍

目前共用 limit 錯誤包括單回應 2 MiB、累計 16 MiB、10,000 訊息／100 頁、單提問 262,144 字元、深度 32 與結構節點數等。未知實際觸發哪一項，不能先宣稱單頁大小已定因。歷史回應含回答與 metadata，即使目錄只存提問，仍可能碰到回應大小上限。

先區分固定超限類型與數值（limit/observed、來源階段、已完成頁數），不得記錄聊天正文、登入 token/cookie、訊息 ID、完整網址、帳號資料、raw response 或內容 hash。診斷結果須獨立於導航提示保存到下次明確載入或頁面停用，不能被正常刷新覆寫；完整索引數與掛載索引數分開。

若確認 paginated response 單頁超限，可降低每次 num_turns 並保留完整分頁、穩定 cursor／head 核對；總量／時間／訊息數限制仍有界。不以任意放大上限或默默截斷宣稱全部讀完。單一提問、legacy 整體回應或總量超限另行處理，不能把小頁策略當成所有超限的解法。

## 必須先完成的真實驗收

1. 在真實 Firefox 長對話與正常登入狀態，記錄實際安裝版本和 runtime SHA；成功讀取正常同來源歷史，不能以 localhost token 代替。
2. 對一段已知提問全集合的長對話核对精確總數、順序與目前分支。只抽查首／中／尾不足以證明全量。私有內容／IDs僅在本機記憶體比較，保存結果只含總數、一致性與失敗原因。
3. 初始畫面只掛載部分訊息時完整目錄仍大於掛載数；捲動到首、中、尾後完整筆數與離屏提問搜尋結果保持，沒有正常卸載造成撤銷。
4. 舊對話及新增長對話分別驗證；換頁、編輯／重新生成、分支切換不混合舊資料，失敗／停止後不套用晚到部分結果。
5. 未掛載定位另驗收十個跨首／中／尾目標，記錄實際命中與失敗，不能把完整目錄成功當作跳轉成功。
6. sub-agent 對固定 source SHA 審查／複驗；合成回歸、真實結果和未通過門檻分開記錄。

**未取得以上真實驗收結果前，不交付另一個宣稱已修好的安裝包，也不把 LIVE 改成 PASS。** 如需使用者協助取得無內容診斷，明確說明它是排錯步驟，不是修復完成交付。

## 目前工具限制

目前可用瀏覽器控制通道只有 Codex 內建瀏覽器及 MCP Apps，沒有 Firefox 分頁通道。先前直接查看 Firefox 被網址政策限制拒絕；不以其他自動化、profile/cookie 複製或遠端除錯繞過。使用者已同意檢查 Firefox，但同意沒有改變工具能力。真實驗收需可用的受允許 Firefox 通道或使用者參與本機測試；尚未執行，不能補寫 PASS。
